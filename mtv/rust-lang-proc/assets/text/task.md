# Постановка задачи
Константы – это элементы данных, значения которых известны и в процессе выполнения программы не изменяются.
Для описания констант в языке Rust используется служебное слово `const` с обязательным указанием типа константы.

Формат записи: `const ИМЯ: тип = значение;`.
Тип вещественной константы - `f32` или `f64`.
Значение вещественной константы - вещественный литерал, перед которым может стоять знак `-`.
Может иметь вид:
1. Вещественная константы с фиксированной точкой - действительное число, представленное в виде целой и дробной частей, разделенных точкой. Пример: `0.1 ; 0. ; -0.`.
2. Вещественная константа с плавающей точкой - действительное число, представленное в экспоненциальной форме. Для символа экспоненты используется символ `e` или `E`. Пример: `1e1 ; 10E-2`.
3. Вещественная константа с суффиксом типа - число (с `.` или без), за которым сразу следует суффикс `f32` или `f64`. Пример: `1f32 ; -1.0f64`.

В связи с разработанной автоматной грамматикой G[‹Def›] синтаксический анализатор (парсер) вещественных констант будет считать верными следующие записи констант:
1. `const with_point: f32 = 0.001;`
2. `const exponential: f64 = 1E-10;`
3. `const suffixed: f64 = 204.24f64;`
